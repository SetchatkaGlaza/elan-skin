# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-12

Первый завершённый релиз.

### Добавлено
- Одностраничный лендинг ÉLAN SKIN из 12 секций: шапка, Hero, знакомство с продуктом, преимущества, текстура, формула, применение, покупка, дополнительное предложение, философия бренда, FAQ, финальный CTA и подвал.
- Демонстрационная корзина с сохранением в `localStorage`, мини-корзина, выбор комплектации, галерея.
- Страницы-документы: политика конфиденциальности, условия покупки, доставка и возврат.
- Видео-секция «Текстура» (WebM + MP4), форма подписки с валидацией.
- Фирменный набор иконок: SVG, ICO, apple-touch-icon, PWA-иконки, `site.webmanifest`.
- Многостраничная сборка Vite, workflow публикации на GitHub Pages.

### Доступность и производительность
- Семантическая разметка, видимый фокус, skip-link, управление с клавиатуры (меню, FAQ, корзина).
- Поддержка `prefers-reduced-motion`; контраст текста не ниже 4.5:1.
- WebP-изображения с `srcset`, `loading="lazy"`, заданные размеры, локальные шрифты.
